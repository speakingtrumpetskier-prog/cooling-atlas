# Cooling Atlas
Seven ways a data center sheds heat — an interactive 3D exhibit. Accurate first, beautiful second.

**Live: https://speakingtrumpetskier-prog.github.io/cooling-atlas/**

Guided tour (10 chapters, ~14 min) or free-range exploration. Every labeled component
opens a cited card: what it is, what moves, the numbers, and — where relevant — water
and chemicals. `BRIEFING.md` is the standalone sourced memo on discharge frequency and
PFAS. Entirely self-contained: one HTML file, procedural geometry and textures, no
external assets.
